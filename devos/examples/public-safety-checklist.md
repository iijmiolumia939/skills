# Public Safety Checklist

Use this checklist before publishing an extraction.

## Include Only

- generic documentation
- reusable prompts
- templates
- small examples that are understandable on their own
- public-safe diagrams or text flows

## Exclude

- private project history
- generated proof archives
- private defect logs
- domain-specific validators
- experimental prototypes
- hard-coded repository paths
- examples that require hidden context

## Scan

Search for:

- private repository names
- private module names
- domain-specific terms
- stale evidence IDs
- broken relative links
- generated artifacts
- credentials or local machine paths

## Review

Ask an adversary reviewer: What would be misunderstood if this were read by someone without the source repository?
